Micromouse floodfill, live

The mouse starts in the bottom-left corner and knows nothing about the maze. Each time it enters a cell it sees that cell's walls, re-runs Flood() on what it knows, and steps to the lowest-numbered open neighbour. Once it reaches the centre it explores back home, then races the shortest path it has proven.

void Flood() {
  std::queue<pii> q;
  // every cell starts "infinitely" far
  ...
  // the 4 centre cells are distance 0
  for (goal : goals) { dist = 0; q.push(goal); }
  while (!q.empty()) {
    auto [x, y] = q.front(); q.pop();
    for (int d = 0; d < 4; d++) {
      if (wall[x][y][d] == 1) continue; // known wall
      if (dist[nx][ny] > dist[x][y] + 1) {
        dist[nx][ny] = dist[x][y] + 1;
        q.push({nx, ny});
      }
    }
  }
}
