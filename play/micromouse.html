Floodfill, live

The mouse starts in the bottom-left corner and knows nothing about the maze. In each new cell it senses the walls, re-runs Flood() on what it knows and steps to the lowest-numbered open neighbour.

What you see

  • Walls the mouse has sensed
  • Hidden walls (tick the box)
  • Path explored so far
  • Final speed-run path
  • Distance map: darker is closer to the target

How a run goes

  1. Explore until the centre is reached
  2. Explore back to the start
  3. Race the shortest path it has proven
The same logic in my firmwareC++
void Flood() {
  std::queue<pii> q;
  // every cell starts "infinitely" far
  ...
  // the 4 centre cells are distance 0
  for (goal : goals) { dist = 0; q.push(goal); }
  while (!q.empty()) {
    auto [x, y] = q.front(); q.pop();
    for (int d = 0; d < 4; d++) {
      if (wall[x][y][d] == 1) continue; // known wall
      if (dist[nx][ny] > dist[x][y] + 1) {
        dist[nx][ny] = dist[x][y] + 1;
        q.push({nx, ny});
      }
    }
  }
}
On the robot this runs on an STM32H743 in well under a millisecond.
