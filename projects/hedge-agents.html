01The project

A personal research system that watches markets on a schedule: a deep cycle once a day and an intraday cycle every 30 minutes on weekdays, both running on Linux in the cloud. Each agent looks at one angle (fundamentals, valuation, catalysts, institutional flow, moat, macro) and returns a normalised score.

The idea is that no single signal is enough. A weighted engine merges the scores, and the top conviction tier needs several agents to agree plus a fresh written thesis from an LLM. Everything sits behind a safety layer.

02What I did

  • Ten agent modules feeding one scoring engine; only two of them call an LLM.
  • Conviction tiers (HIGH, MEDIUM, LOW, Watch) with explicit rules, so every decision can be traced.
  • Safety layer: kill switch, maximum actions per day, heartbeat and a token-protected halt endpoint.
  • One LLM router with budget caps and retry, so model costs and outages cannot run away.
  • Telegram alerts and scheduled runs on GitHub Actions; the code stays private.

conviction.py: how a tier is decided (excerpt)Python
def _tier_for(agg, agreement, llm_conviction, has_required,
              llm_outage=False, llm_fresh_long=False) -> Tier:
    if not has_required:
        return Tier.WATCH
    for tier in (Tier.HIGH, Tier.MEDIUM, Tier.LOW):
        min_agg, min_agree, min_llm_conv = TIER_RULES[tier]
        if tier is Tier.HIGH and not llm_fresh_long:
            continue
        if llm_outage:
            # a HIGH position is never granted without a fresh LLM read
            if tier is Tier.HIGH:
                continue
            llm_ok = True
        else:
            llm_ok = (llm_conviction or 0.0) >= min_llm_conv
        if agg >= min_agg and agreement >= min_agree and llm_ok:
            return tier
    return Tier.WATCH
Graceful degradation: if the LLM is down, lower tiers still work, but the top tier is withheld.
