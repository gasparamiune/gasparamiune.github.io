# gasparamiune.github.io

Visual portfolio of Gaspar Amiune: https://gasparamiune.github.io

## How it is built

- `index.html`, `projects/*.html`, `play/micromouse.html` and `404.html` are generated by `_src/build.py` from `_src/content.py`, the one source for every text, link and image.
- `assets/site.css` is the design: an engineering drawing sheet (paper, ink, one signal colour, figure numbers, title blocks). Light by default, with a dark mode.
- `assets/maze.js` is a floodfill simulator based on the algorithm in my Micromouse firmware. It drives the interactive page and the small live mazes.
- `assets/site.js` handles the theme, filters, the figure viewer and the live previews.
- Every image is a real render, simulation, screenshot or photo from the project itself. Work that is designed or simulated but not built is labelled that way.

Rebuild after editing content:

```
python3 _src/build.py
```

The build needs Python 3 with Pillow (it reads image sizes).
