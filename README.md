# gasparamiune.github.io

Visual portfolio of Gaspar Amiune: https://gasparamiune.github.io

- `index.html`, `projects/*.html` are generated by `_src/build.py` from `_src/content.py` (one source for every text, link and image).
- `play/micromouse.html` is an interactive floodfill simulator based on the algorithm in my Micromouse firmware.
- `assets/` holds styles, scripts, images and videos. Every image is a real render, simulation, screenshot or photo from the project itself.

Rebuild after editing content: `python3 _src/build.py`
