def _tier_for(agg, agreement, llm_conviction, has_required,
              llm_outage=False, llm_fresh_long=False) -> Tier:
    if not has_required:
        return Tier.WATCH
    for tier in (Tier.HIGH, Tier.MEDIUM, Tier.LOW):
        min_agg, min_agree, min_llm_conv = TIER_RULES[tier]
        if tier is Tier.HIGH and not llm_fresh_long:
            continue
        if llm_outage:
            # a HIGH position is never granted without a fresh LLM read
            if tier is Tier.HIGH:
                continue
            llm_ok = True
        else:
            llm_ok = (llm_conviction or 0.0) >= min_llm_conv
        if agg >= min_agg and agreement >= min_agree and llm_ok:
            return tier
    return Tier.WATCH

About

Engineer first, AI-native by habit

I grew up in Argentina, moved to Italy and then to Denmark, and I study Mechatronics at SDU while working. I like projects where mechanics, electronics and software have to agree, and I like shipping them.

I use Claude every day to build. What I care about most is the system around the code: clear requirements, one source of truth for every number, automatic checks, and honest labels on what is simulated and what is real.

Languages: Spanish (native), English (C1), Italian (C1), Danish (B1), Russian (A1).
